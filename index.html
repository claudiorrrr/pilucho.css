pilucho.css

A classless CSS framework. Drop it in, write semantic HTML, get a good-looking page. No classes needed.

Usage

<link rel="stylesheet" href="pilucho.css">

That's it. Write your HTML and it just works. See the test page for every styled element.

Theming

Override CSS custom properties:

:root {
  --bg: #fafafa;
  --text: #333;
  --accent: #0055ff;
  --accent-hover: #0033cc;
  --font-sans: "Inter", sans-serif;
}

Development

npm run dev     # serve locally
npm run build   # minify
